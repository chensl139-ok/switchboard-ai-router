# macOS 桌面 App

桌面版使用原生 AppKit / WKWebView 窗口，内置 Node 和生产依赖。安装使用时不需要 Docker、Node、npm 或终端。当前可在 Apple Silicon Mac 上构建和使用，最低系统为 macOS 13。

## 安装与使用

1. 双击打开 `Switchboard-<版本>-macOS-arm64.dmg`。
2. 将窗口中的 `Switchboard.app` 拖到旁边的 `Applications（应用程序）` 文件夹。
3. 复制完成后，从“应用程序”打开 Switchboard，再推出安装磁盘；不要直接从 DMG 内运行。

当前安装包适用于 **macOS 13 及以上的 Apple Silicon Mac（M 系列）**，不是 Windows 或 Intel Mac 安装包。当前使用 ad-hoc 签名，尚无 Apple Developer ID 签名和公证；其他电脑下载后可能被系统安全检查阻止。正式分发前需完成签名与公证，不应要求接收者关闭安全检查。

升级时先退出正在运行的 App，再拖入新版并确认替换应用程序。此操作不删除下面说明的用户数据目录。

首次启动会自动创建本机配置。填写姓名、邮箱和至少 12 位密码，创建管理员账户；初始化令牌由桌面 App 安全地传给本机页面，无需手动编辑 `.env`。之后直接使用平台页面配置服务商和模型。

顶部显示当前 API 地址，默认 `http://127.0.0.1:3110/v1`，旁边可一键复制。端口占用时会自动分配另一可用端口，以界面显示为准。服务仅绑定本机，其他电脑无法通过此地址访问。关闭窗口后 App 继续运行，可从 macOS 菜单栏的 Switchboard 图标重新打开、查看服务地址或进入实验室；按 `⌘Q` 退出会停止本机 API 服务。菜单状态随服务启动／停止更新，不额外轮询 API。

`⌘1` 打开工作空间，`⌘2` 进入模型实验室，`⌘3` 进入路由策略，`⌘4` 进入服务商与模型。这些入口仍受平台登录与角色权限控制。工具条仅保留复制地址、浏览器打开和刷新；导入与数据目录放在「Switchboard」菜单中。

“导入已有部署…”可选择包含 `.env` 与 `data/` 的项目目录。导入创建独立副本，保留原部署和前一个桌面配置。SQLite 使用备份接口复制，旧登录会话不会迁移。建议先停止原服务以保证多个数据文件的一致性。导入失败时原桌面配置仍保留；从菜单重启可恢复。

数据位于 `~/Library/Application Support/Switchboard/profiles/`，通过菜单“打开数据目录”访问。升级只替换 `.app`，不要删除此目录。备份时应退出 App，并保存整个 `Switchboard` 数据目录，包括 `.env`、`master.key` 及所有租户数据。

导入已有飞书企业配置后，可直接在 App 中点击“使用飞书登录”，选择对应企业。App 使用 macOS 系统认证会话打开浏览器授权，登录成功后自动回到工作空间；企业身份连接也使用这一流程。是否直接使用已有飞书会话、需要扫码或唤起飞书客户端，由飞书授权页决定，App 不会跳过用户授权。

每个已绑定企业的飞书应用都需要在“安全设置 → 重定向 URL”**新增** `http://127.0.0.1:3110/api/account/sso/feishu/callback`，保留原部署的回调。App 不覆盖导入的 `.env` 或企业绑定配置。端口占用时仍可使用邮箱登录；若要使用飞书，应释放 3110 后重启 App，或登记实际端口的回调。菜单“飞书登录配置说明”可复制当前回调地址。首次登记后可能需要企业管理员发布/审批应用。

浏览器只取得短时、一次性授权票据；登录会话不放在 URL 中。授权结果仅可由发起登录的本机 App 兑换，并在兑换后立即失效；取消、超时和退出均清理未完成的登录结果。完整登录由本人在飞书授权页完成。

## 分享安装包

分享生成的 `.dmg`，可同时附上同一构建的 `SHA256SUMS` 供接收者校验。安装包只含程序及运行依赖，不含打包者的账号、服务商密钥、个人订阅授权或历史数据。不要分发 `.env`、`master.key`、用户数据目录或备份。

同事安装后得到的是**独立的本地平台**，需要自行初始化并配置服务商；安装同一个 App 不会自动加入你的租户、共享你的模型额度或连接你的平台。若要多人共用同一组织，应使用同一中心部署的访问地址，而不是各自电脑的 `127.0.0.1`。

## 个人订阅连接（本机预览）

进入「服务商与模型」，在「个人订阅服务商」点击 **Continue with ChatGPT**，由本人在系统浏览器的 OpenAI 官方页面登录并授权。完成后点击「返回 Switchboard」或切回 App；账户会以订阅卡片显示，可选择默认实验模型、刷新模型或断开连接。点击「在实验室对话」，或在「模型实验室」选择带“个人订阅”的模型，直接使用统一对话页面。此流程不需要 API Key，也不会导入或读取 Codex / Claude 已保存的登录凭证。

当前使用 [Sign in with ChatGPT 的开源客户端流程](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)。账户是否支持、可选模型和用量额度由 OpenAI 返回；只有有效身份且获得 `chatgpt.tokens.use.direct` 权限才能调用。请求使用官方 Responses API，固定 `store:false`、`stream:true`，在实验室流式显示，收到 `response.completed` 后才标记成功。支持统一 Markdown、性能指标与按用户／租户隔离的实验历史；暂不支持图片、工具、生成参数自定义或多模型对比。

在「路由策略 → 仅我的实验室」点击「为我单独设置」，选择首选模型和失败后的备用方式；右侧会检查草稿顺序，点击「保存并生效」后，在模型实验室选择「个人自动路由」。支持同订阅不同模型，以及本人订阅与组织 API 模型之间切换；可手动指定严格备用顺序。默认跟随团队，也可恢复跟随；凭证不共享。进阶设置中的经济优先不会假定订阅免费，只选择具有有效价格的 API 模型。个人设置不改变团队配置，团队请求量／并发上限仍有效。已开始返回正文后不再切换，以免拼接回答。直接选择某个订阅模型仍是固定调用，不自动消耗组织 API 额度。

连接严格按平台用户和租户隔离，不出现在组织共享服务商中，业务 API Key 不能调用这些订阅。此预览不是订阅号池，也不支持 Claude 订阅共享或订阅额度转售。组织级对外共享仍需供应商许可及相应接入方案。

Claude 订阅尚未接入：Anthropic 的[官方认证说明](https://support.claude.com/en/articles/13189465-log-in-to-your-claude-account)要求面向他人的产品使用 Console API 或支持的云平台；获准第三方工具也可能从额外 usage credits 扣费，而非订阅额度。当前不冒充 Claude Code、复用其登录令牌或把 API Key 接入标为订阅。只有取得适用于 Switchboard 的官方客户端授权与接入规格后，才可实现 Claude 订阅连接。

连接按钮会显示授权打开状态；浏览器未打开时可重新发起授权。App 会报告系统浏览器启动错误。授权链接一次性且十分钟有效，重启或重新发起后旧链接不能复用；在官方页面取消授权不会删除原有连接。

凭证在本机 `chatgpt-plan.json` 中加密存储，旋转刷新令牌串行更新；浏览器只显示账户标签和状态。断开会清除本地凭证并尝试撤销官方授权；若网络导致撤销未确认，可在 [ChatGPT 用量设置](https://chatgpt.com/settings/usage) 中检查。请随完整 App 数据目录一起备份；不要单独复制凭证文件到另一台设备。

## 开发与打包

需要 macOS、Xcode Command Line Tools、符合项目要求的官方独立 Node 二进制以及 npm 开发依赖：

```sh
npm ci
npm run build:desktop
```

产物在 `dist/desktop/`：App、DMG、SHA256SUMS。打包脚本会校验运行时架构和动态库依赖，执行前端生产构建，只复制程序与生产依赖，排除已编译的 Vue／TypeScript 前端源文件、重复入口与依赖 source map；仅对安装包内的 Node 副本移除调试／局部符号，保留公开符号并重新签名、验证 SQLite 和生产依赖，不修改构建机器的 Node。`.env`、`data/`、测试及本地账号密钥不包含在安装包中。Node 与依赖的许可证随 App 保存。安装包的大部分空间是独立运行所需的 Node，系统 WebKit 不随包重复安装。

默认使用构建时的 `process.execPath`；可通过 `SWITCHBOARD_NODE_BINARY` 指定同架构的官方 Node。原生窗口与运行时必须是同一架构。Intel 包需在对应环境构建并验收；当前交付不含 Windows 安装程序。

当前产物使用本地 ad-hoc 签名，适用于本机安装；没有 Apple Developer ID 签名和公证。向其他电脑正式分发前，应配置开发者签名、加固运行时和公证流水线。不要以关闭系统安全检查作为安装步骤。
