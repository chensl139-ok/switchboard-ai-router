# 可复现的产品导览

中英文 README 共用此目录的 7 张实际浏览器截图，覆盖概览、服务商、路由、对话、历史详情、接入和深色用量分析。截图日期：2026-11-01。使用虚构账号、虚构服务商和模拟上游，不含真实租户数据；性能数字不可作为基准。

```sh
npm ci
npm run demo
```

脚本创建独立临时目录，只监听 `127.0.0.1` 随机端口，输出演示地址和演示登录。所有上游请求均由进程内模拟实现，其他目标会被拒绝；不读取生产 `.env`、数据库或真实模型凭证。通过平台 API 创建服务商、路由和业务 Key，并验证模拟调用。

登录后可发送对话、查看历史、预览路由与切换主题。按 Ctrl+C 停止后清理临时数据；不要将演示实例对公网开放。

更新素材时使用实际浏览器截图，不用设计稿冒充运行画面。检查无真实账号、密钥或内部地址后替换对应 JPG。截图不参与 Docker 或桌面 App 打包。
