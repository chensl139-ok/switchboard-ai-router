# 可复现的产品导览

版本：**3.1.1，2026-11-26**。中英文 README 共用本目录素材，导览覆盖工作台与网关双区；截图来自隔离演示实例。

使用虚构账号、虚构服务商和模拟上游，**不保存真实租户、密钥、私人会话或内部地址**。画面中的延迟、吞吐、Token 与费用只是演示数据，不是性能基准、供应商账单或真实上游可用性证明。

## 启动隔离环境

在仓库根目录执行：

```sh
npm ci
npm run demo
```

脚本创建独立临时目录，只监听 `127.0.0.1` 随机端口，输出演示地址与登录信息。上游由进程内模拟实现，其他目标会被拒绝；不读取生产 `.env`、数据库或真实模型凭据。通过平台 API 准备服务商、路由和业务 Key，并验证模拟调用。

不要填写真实凭据或把此实例对公网开放。Ctrl+C 停止后清理临时数据；会话“持久”是该实例内的存储行为，不代表临时 demo 数据在退出后保留。

## 建议演示与验收流程

1. 打开空白新会话并离开，确认没有多出空记录；输入一条虚构文字草稿后刷新，验证恢复。发送模拟调用后检查本地自动标题，不产生标题模型请求；旧手动标题不被替换。
2. 搜索、重命名、置顶、归档、取消归档、删除，刷新确认删除未生成替代记录；个人收藏仅属于本人当前租户。
3. 编辑用户消息，仅出现新分支草稿、不自动发送；助手重试需确认可能计费，保留原分支与原回答。JSON／Markdown／文本导出后检查内容，Markdown／文本默认不含思考。
4. 多页或模拟断网检查 CAS／删除冲突：409 重新加载并确认，网络失败保留本地；创建结果不确定先导出再刷新核对，不按标题猜删。生成中／过期租约的处理与普通删除分开。
5. 完整旧文本快照可显式导入；缺失图片／视频或工具上下文不能假装继续原上下文。媒体任务查询与重新生成分别演示，明确结果 URL 可能过期。
6. 检查明暗主题和窄屏，确保无账号、密钥、个人文本或生产域名进入截图；记录实际测试结果，不以演示替代真实上游或 OAuth 验收。
