## 验收中修复的问题

1. 删除当前会话后立即新建并保存同名空会话，造成“删不掉”；同时处理空白离页落库、旧保存错误阻止删除和迟到保存复活风险。
2. 持久会话地址在重新渲染时强制回到聊天，导致模型对比无法打开。

没有删除、重置或灌入真实用户会话来完成这些测试。图片、WAV、WebM 素材由隔离测试生成；浏览器 HTTPS 媒体响应由测试拦截提供，不访问真实媒体服务。

## 未验证及不包含

- 未对所有真实供应商和模型逐一生成；真实额度、价格、可用范围和网络状态需部署方自行核对。
- 未执行真实付费图片、音频或视频生成，也未验证真实素材结果链接的长期有效性。
- 未验证真实手机软键盘、所有反向代理的长连接行为或高并发压测；没有进行DoS类测试。
- 本轮没有构建或签发新的 macOS/Windows 原生安装包；Docker 发布不能代替桌面专属个人订阅功能验收。
- GitHub Actions、Release附件、GHCR双架构digest和最终部署应按[发布维护](../.github/RELEASING.md)另行核验，不能用本地测试结果替代产物发布成功。
