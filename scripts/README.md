# 维护脚本索引

日常部署优先使用根目录的 `compose.yaml`；脚本不是后台服务管理器。操作 `data/` 前，先确认当前目录、租户范围与备份，并停止运行中的实例。

| 脚本 | 用途与边界 |
| --- | --- |
| `setup.mjs` | 首次生成 `.env` 与随机令牌；已存在的 `.env` 不会覆盖 |
| `smoke.mjs` | 检查就绪状态和模型列表；加 `--live` 会发送一次可能计费的真实调用 |
| `reset-admin-password.mjs` | 停机后恢复默认租户所有者密码；会撤销该账户的旧会话 |
| `clear-history.mjs` | 先省略 `--apply` 预览，再停机并执行清理；应用时会先备份完整数据目录 |
| `set-price-expiry.mjs` | 预览／备份后批量调整价格期限；`--apply` 才会修改数据 |

旧式进程恢复、一次性服务商迁移和价格快照脚本已从当前版本移除，需要追溯时可从 Git 历史读取。日常服务商增删、模型选择和价格维护应通过控制台完成。
